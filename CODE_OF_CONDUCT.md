# Community conduct

Treat contributors with respect. Discuss code and evidence; avoid personal
attacks, harassment, discrimination, threats, and disclosure of private data.
Make room for contributors with different backgrounds and levels of experience.

These expectations apply to issues, pull requests, and other project spaces.
Maintainers may edit or remove harmful content and restrict participation.
Report conduct concerns privately to a maintainer through an available private
contact; if none is listed, request one without posting personal details.
Reports should be handled discreetly and fairly, including concerns about a
maintainer. This policy does not promise a response deadline.
